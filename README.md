# Encrypted-chat-application-in-python
Encrypted networking chat application in python with simple Tkinter GUI 

-IMPLEMENTED-
- TCP server
- Client connects to server and picks username
- Server relays messages between two connected clients
- Basic send/receive
- Shared AES key
- Encrypt messages before sending and decrypt at arrival
- Not phishable on the wire
- Timestamped messages
- GUI simple interface


-AREAS OF IMPROVEMENT- 
- File/images exchange
- Emogis implementation 
- Messages auto-deletion after a certain period of time 
- Modern GUI
